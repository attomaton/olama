# Как установить локальную модель на Windows

Эта инструкция устанавливает только Ollama и модель Qwen3 4B Instruct. GitHub, Python, Telegram-бот и API-ключи не нужны.

## 1. Установите Ollama

Откройте [официальную страницу Ollama для Windows](https://ollama.com/download/windows), скачайте установщик и запустите его. Поддерживается Windows 10 версии 22H2 или новее. Для программы потребуется около 4 ГБ свободного места, для модели — ещё примерно 2,5 ГБ. Видеокарта не обязательна, но может ускорить ответы.

После установки откройте **новое** окно PowerShell и проверьте команду:

```powershell
ollama --version
```

Если PowerShell пишет, что команда `ollama` не найдена, закройте и снова откройте окно PowerShell. При необходимости запустите Ollama из меню «Пуск».

## 2. Скачайте модель

В PowerShell выполните:

```powershell
ollama pull qwen3:4b-instruct
```

Дождитесь завершения загрузки. Чтобы убедиться, что модель установлена:

```powershell
ollama list
```

В списке должна появиться `qwen3:4b-instruct`.

## 3. Начните общение

```powershell
ollama run qwen3:4b-instruct
```

Введите вопрос и нажмите Enter. Для выхода из чата введите `/bye`. Чтобы открыть чат позднее, снова выполните `ollama run qwen3:4b-instruct`. После загрузки модели для общения с ней интернет не нужен.

Если появится ошибка подключения к Ollama, запустите приложение **Ollama** из меню «Пуск» и повторите команду.

Источники: [установка Ollama на Windows](https://docs.ollama.com/windows), [страница модели Qwen3 4B Instruct](https://ollama.com/library/qwen3:4b-instruct).
